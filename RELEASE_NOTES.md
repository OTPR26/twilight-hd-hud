# Twilight HD HUD v1.3.1 — Menu Input Hotfix

Fixes L, R, ZL, and ZR still activating gameplay actions while Dusklight's
menu is open. This also covers the equivalent Xbox and PlayStation controls.

Shoulders and triggers held when the menu closes must be released before
they can activate gameplay again, preventing accidental actions on return.

This is a single-fix update to v1.3.0. Fonts, HUD sizing, layouts, saved
settings, and controller bindings are unchanged.

## Updating

Replace the existing mod package, then fully restart Dusklight.
Requires **Dusklight v1.4.1-141 or newer**.

## Downloads

- **Twilight-HD-HUD-Desktop-Android.dusk:** Windows x64, Linux x64,
  macOS Apple Silicon, and Android ARM64.
- **Twilight-HD-HUD-iOS-tvOS.dusk:** iOS and tvOS ARM64.
