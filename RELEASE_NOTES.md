### Which download should I use?

- **Twilight-HD-HUD.dusk** — Windows, Linux, macOS, Android, and iOS (eight targets). Upload this file to the mod site.
- **Twilight-HD-HUD-tvOS.dusk** — separate Apple TV package.

Install only one package. iOS and tvOS still require bundling and signing with Dusklight.

### Legacy downloads — ignore for manual installation

**Twilight-HD-HUD-Desktop-Android.dusk** and **Twilight-HD-HUD-iOS-tvOS.dusk** are retained only for compatibility with older in-mod update checks. They are not additional mods or required downloads. For manual installation, ignore these legacy files and choose one of the two packages above.
