# Universal Silver

Created with the built-in image tool from the existing silver A button.
The source alpha is preserved; the texture encoder fits its transparent bounds
to the original button canvas. All four Universal face prompts share this sprite.

## Initial prompt

Edit target: the attached silver circular game controller button icon. Remove ONLY the dark A letter and its letter-shaped shadow from its face, replacing that region with the matching uninterrupted light silver-gray face surface. Preserve the exact circular silhouette, slightly beveled off-white rim, soft silver-gray shading, perspective, dark lower drop shadow, placement and padding from the reference. Do not redesign the icon or change its shape, brightness, or finish. No letters, symbols, marks or additional elements. Genuine transparent background outside the icon, preserve the existing soft shadow. Produce one clean high-resolution letterless silver button sprite.

## Final cleanup prompt

Use case: precise-object-edit. Image 1 is the edit target: a blank silver game-controller button sprite whose face still contains cloudy A-shaped ghosting. Replace the entire INNER FACE with a clean, smooth, nearly uniform light silver-gray surface, with only a subtle simple top-to-bottom lighting gradient. Remove ALL cloudy mottling, triangular shapes, strokes, letter remnants, embossing and symbol-shaped shadows. This must read as completely blank even when reduced to a 50-pixel HUD icon. Preserve the existing outer silhouette, bright beveled white-silver rim, dark lower drop shadow, viewpoint, padding and proportions. No letters or symbols of any kind. Keep genuine alpha transparency outside the button, not a black or checkerboard background. Change only the inner surface shading; do not redesign the button.
