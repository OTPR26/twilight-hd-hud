# Fish artwork

Generated with the built-in image tool, then given a separate background-extraction pass. These are newly rendered interpretations of the reference designs, not extracted TPHD assets.

## Cleanup prompt (each fish)

Preserve the fish itself exactly: markings, color, silhouette, fins and whiskers. Remove all surrounding background and glow. Output a clean isolated cutout with genuinely transparent alpha outside the fish, opaque body, antialiased edges. No shadows, glow, vignette, text or additional elements.

Compile using tools/encode_fish_artwork.cjs. PNG masters are retained; game textures are 512 pixels wide, proportionally sized, alpha-preserving tiled RGBA8. Native fish artwork remains the runtime fallback.
